# Security

Do not publish credentials, account archives or transcripts in issues. Use GitHub's private vulnerability reporting when available; otherwise open a minimal issue asking for a private reporting channel without exploit details or user data.

SessionPier delegates authentication to official provider clients. Account labels, normalized usage cache and local profile directories remain on the user's Mac. Shared history is opt-in for newly created profiles. Remote Control is blocked for profiles marked shared, but provider organization policies and cloud behavior remain outside this app's control.

Treat all beta releases as early software. Review the source before installing it in a sensitive environment. Signed and notarized distribution is planned.
